Re-run with corrections

QUBO continuum rows now use the connectivity repair (QUBOOptions.connectivity, on by default): after each update, floating pieces are removed or re-attached to the supports, so the binary design stays one grounded body with every load on solid. Results from before the fix (e.g. an old results/quick; marked pre-fix below) may contain floating material — on the bridge deck a crisp compliance orders of magnitude too high. Re-run, then read the audit columns: a row that fails the physics check is labelled physically invalid.

CLI: python -m freeto.study --suite quick --out results/quick --threads 1
